## 2026-10-22 · v0.1.0 首个版本

背景：健康助手（clawbot-health-buddy）已经接到女朋友的微信，自己微信里的 ClawBot 闲置，做一个给自己用的开发助手。

决定：
- 新建独立仓库，架构沿用健康助手（iLink 长轮询 + DeepSeek + SQLite + systemd），但目录、服务名、包名、数据库全部分开，不监听端口。

- 推送超出微信 23 小时窗口时暂存，等用户说话补发；窗口快关时在热榜末尾提醒回一句。
